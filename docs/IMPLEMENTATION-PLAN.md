# Implementation plan

## Milestone 1 — Foundation (complete)

App Router project, design tokens, brand mark, shared navigation/footer, homepage, subject routes, catalogue, and responsive layout.

## Milestone 2 — Learning workflow (complete)

Reusable VLab-style Aim, theory, pretest, procedure, deterministic simulation, posttest, references, feedback, printable report, and local progress architecture.

## Milestone 3 — Validation and handoff (in progress)

Run lint, type checking, unit tests, production build, and browser smoke checks where supported. Record limitations. The repository/account handoff remains open until the intended GitHub login is connected.

## Future milestone — Course material integration

Review the supplied experiment inventory with faculty, approve calculations and question keys, add validated modules one at a time, and re-run the full check suite.

## Definition of done

All product routes render; catalogue controls work; simulations match documented models; local progress fails safely; reports print; docs are present; responsive/accessibility behavior is reviewed; available checks have actual results.
