# Assessment standards

Assessment content lives with the typed experiment registry and remains separate from presentation components. Each question includes a stable identifier, prompt, four options, correct-option index, and explanation.

## Validation process

1. Review wording for one clear interpretation and appropriate prerequisites.
2. Independently verify each answer key and numerical calculation.
3. Confirm distractors are plausible but unambiguously incorrect under the stated assumptions.
4. Check keyboard selection, submission gating, score calculation, answer review, and explanation display.
5. Record the reviewer and review date before marking any questions faculty-verified.

Current questions are sample practice only. Scores are private reflection signals, not grades or official student records.
