# User flows

## Find a module

Home → Explore labs → search/filter/sort → select a labelled sample module → Aim.

## Complete a learning loop

Aim → Theory → Pretest → Procedure → Simulation → Posttest → References → Feedback → Report. Every section is directly selectable from the stage navigation. Assessment steps require all displayed questions to be answered and submitted before continuing. Completion is recorded after the submitted Posttest when the learner continues.

## Browse a subject

Home or catalogue → subject collection → module card → reusable experiment workflow.

## Review progress

Home progress preview or navigation → My progress → inspect completed modules and saved scores → reopen a module.

## Navigation

The global header links to the catalogue, subject collections, and progress. Cards and footer links lead to real routes. A mobile menu exposes the same destinations.
